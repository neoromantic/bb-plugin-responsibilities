# Demo provenance

`responsibilities.png` and `new-child.png` are unmodified screenshots of official BB 0.47.1, captured on 31 October 2026 in an isolated disposable runtime. All titles, messages, states and manager entries are synthetic. No provider credentials or real agent runs were used.

Responsibilities 0.1.0 uses public release commit [`e8ceb793902beae4cc66c4e35e1dae71945dad9b`](https://github.com/neoromantic/bb-plugin-responsibilities/tree/e8ceb793902beae4cc66c4e35e1dae71945dad9b). Subthread Columns 0.1.0 was installed with columns off; Model & Effort Badges and True Colors were absent. Provider icons and the working spinner are BB’s own.

- `responsibilities.png` shows failure/question/unread marks and the real Filter threads menu. The parent Release planning is highlighted through an optional synthetic managers JSON file selected in Managers file.
- `new-child.png` shows BB’s real composer opened by **New child thread**, with **Full Access** initially selected. Nothing was submitted and no child or provider run was started. A permission mode chosen before sending is preserved.

Dark theme, 1440×900 CSS pixels at 2× scale; both PNGs 2880×1800. No crop, resize or UI redraw.

## Compact warm theme, 0.2.0

`compact-theme-dark.png` and `compact-theme-light.png` are unmodified screenshots of official BB 0.47.1 with Responsibilities 0.2.0 from this release, captured on 7 November 2026 in an isolated disposable runtime. All threads, messages, states and manager entries are synthetic. No provider credentials or real agent runs were used. Model & Effort Badges and True Colors were disabled; the provider icons are BB's own.

Enable **Compact warm theme**, configure Release planning and Review the navigation as managers, and select their nested Check keyboard focus thread. Capture once with **Settings → Appearance → Theme → Dark** and once with **Light**. Both use the default BB palette beneath the plugin's theme. 1440×900 CSS pixels at 2× scale; PNGs 2880×1800. No crop, resize or UI redraw. Turning the plugin setting off and back on restores the native palette and then reapplies the warm theme without reloading.
